# Hop 三端界面与稳定性验收

macOS、Windows 和鸿蒙 PC 已安装 UI2 测试版。鸿蒙 PC 已升级到支持剪贴板的调试包，包名为 `dev.hop.input`。实际安装包经 SDK 验签，包含带 `ohos.permission.READ_PASTEBOARD` 的新调试 Profile。文本和图片同步仍需真机验收。

1. **添加电脑。** 在连接了物理键鼠的电脑上打开 Hop，选择「添加电脑」。另一端从附近设备中选这台电脑；如果发现失败，再填写局域网地址。首次连接时，在两端核对两组完整指纹。已有配对可以直接连接。
2. **排列两台电脑。** 连接第一台接收端后，主控端打开「空间布局」。把接收端分别拖到本机的左右、上下，检查边缘吸附和穿越位置。切到正视图，确认显示的是同一份位置；多显示器可展开后分别排列。鸿蒙作为接收端在卡片中显示连接状态，由主控端负责排列。
3. **尝试取消跨屏。** 开启共享，把鼠标推到相贴边缘后立即拉回，重复数次；不应退出已配对连接。之后正常进入并返回，检查滚轮、按键组合和屏幕边缘。
4. **检查待机与重连。** 保持两端清醒，空闲十分钟后继续穿越。鸿蒙接收端在已验证连接意外中断后最多尝试三次重连；点击「断开连接」应停止重试。记录发生断连时的主控、接收端、时间以及当时是否在跨屏。
5. **检查可读性。** 在每端看首页、配对和设置：默认页只需要看到状态和下一步；确认页能看全指纹；地址、剪贴板及单设备设置按需打开。macOS 和 Windows 分别检查系统的减少动态效果设置。
6. **检查剪贴板。** Mac 和鸿蒙默认开启同步，两端的 Hop 设置均可关闭。鸿蒙如提示授权，按系统提示操作。开启后重新建立连接并跨屏，分别测试两个方向的文本和图片粘贴。关闭后复测，重启应用确认关闭状态仍在。

空间布局中的绿线标出共享边段。Mac 可选中一台电脑，再用方向按钮把它贴到主显示器旁。以下四种布局已用 Mac 主控和鸿蒙接收代码在加密回环上验证过，表中每行仍可在两台实机上复测。

| 鸿蒙相对 Mac 的位置 | 从 Mac 进入 | 从鸿蒙返回 | 回到 Mac |
| --- | --- | --- | --- |
| 下方 | Mac 底边 | 鸿蒙顶边 | Mac 底边内侧 |
| 上方 | Mac 顶边 | 鸿蒙底边 | Mac 顶边内侧 |
| 左侧 | Mac 左边 | 鸿蒙右边 | Mac 左边内侧 |
| 右侧 | Mac 右边 | 鸿蒙左边 | Mac 右边内侧 |

每次保存后，从绿线中间往返，再在边段两端重复。部分贴合时，未贴合的边缘应留在当前电脑。只碰到角点时不会接通。跨屏后持续推向回程边缘，鼠标应回到 Mac，连接应保持。最后重开布局，核对位置和绿线是否和保存前一致。
